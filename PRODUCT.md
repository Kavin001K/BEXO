# Bexo — Product context

## Register

**Product** — mobile app UI serves portfolio creation; marketing polish on auth/onboarding only.

## Purpose

Bexo helps students and early professionals claim a handle, collect profile data (resume AI parse or manual), and publish a live portfolio site at `{handle}.mybexo.com`.

## Users

- Students and new grads building a first professional presence
- Early-career professionals updating credentials on mobile
- Context: phone in daylight, calm and trustworthy — not a late-night dev tool

## Core jobs

1. Sign in via WhatsApp OTP (low friction, high trust)
2. Complete onboarding (email, photo, handle, resume/manual, theme preferences)
3. Reach **90% profile completeness** to unlock automatic website build
4. Manage portfolio, post updates, view analytics on Home / Portfolio / Post tabs

## Strategic principles

- **One job per screen** in onboarding; always show progress (% and step)
- **90% gate** is the single build unlock — client and server must agree
- **Persistent reminders** on Home until profile is build-ready; resume PDF called out when work history is empty
- **No fake progress** — build UI reflects real `site_builds` status
- Copy is concrete; no "elevate", "seamless", or filler startup language

## Anti-references

- Purple AI-gradient SaaS dashboards
- Dark-only operator UI (this product is **light editorial**)
- Generic 3-column stat cards and identical feature rows
- Fake timers that navigate away before build completes
- Modal-first flows when inline progressive disclosure works

## Tone

Warm, clear, encouraging — like a patient editor helping you publish, not a growth-hacking funnel.
